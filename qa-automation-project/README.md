# 🧪 Projeto de Automação de Testes

## 📌 Descrição
Automação de testes de API e Web utilizando Python.

## 🧰 Tecnologias
- Python
- Pytest
- Requests
- Selenium
- Faker
- GitHub Actions

## ▶️ Como executar

### API
cd api-tests
pip install -r requirements.txt
python -m pytest

### Web
cd web-tests
pip install -r requirements.txt
python -m pytest

## ⚙️ CI/CD
Pipeline executa automaticamente os testes a cada push.

## 📊 Cenários
- API: User, Pet, Store
- Web: Login + Carrinho + Checkout
